# Remaining 101 BASIC ports

All 108 source files from the pinned collection were submitted to `.LOAD` under
CENTOS. Each successfully loaded file was also submitted to `.RUN`. Of those
originals, 31 were refused during loading, 76 reported a BASIC error during
launch, and `banner` aborted in CENTOS. BUNNY and SNOOPY have no source files
in the pinned collection. [Upstream listings and notes](https://github.com/maurymarkowitz/101-BASIC-Computer-Games/tree/45f75052be3f436f2e575f58d4aa611484268227)

The distribution installs 24 ports in `SBASIC` after checking an interaction
or a complete plot in the emulator. The lists below stay available in the upstream
submodule. The diagnostic column records the furthest trial, including experimental
syntax normalization where it reached a later phase. The work column identifies the
first known blocker or the next behavior to verify.

Run the original-listing audit from the Centurion distribution root.

```sh
python3 tests/audit-basic-games.py build/out/image/centos-apps.img basic-games-audit.json --jobs 8
```

The program arena holds 5,632 bytes shared by tokenized source, generated bytecode,
the line index and numeric arrays. Stefan BASIC accepts single-letter variables
and one-dimensional numeric arrays. DEC file operations, string arrays, matrix
operations and printer positioning need source adaptations.
